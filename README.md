# My Resume Website

This is a personal resume website I made to put my academic background, skills, interests and achievements together in one place. I wanted it to feel a little more personal than a regular resume, while still keeping the information easy to find.

The website is built using **HTML and CSS**. I have kept the design colourful, with a dark navy introduction section, bright accent colours and separate sections for the different parts of my profile.

## What the website includes

- **Home:** A short introduction, my name, course details and photograph.
- **About:** A little about my interests and what I would like to explore.
- **Education:** My current programme at IIM Bangalore, IPMAT preparation and school details.
- **Skills:** The business-related and interpersonal skills I am developing.
- **Milestones:** A few academic and extracurricular experiences.
- **Interests:** Topics I enjoy learning more about, such as finance, business strategy and marketing.
- **Contact:** My contact details.

## Tools and technologies

- **HTML5** – used to organise the content and create the different sections of the website.
- **CSS3** – used for the colours, typography, layout, spacing, responsive design, hover effects and other visual details.
- **Visual Studio Code or another text editor** – can be used to edit the files.
- **GitHub and GitHub Pages** – planned for storing the project and publishing the website.

The website does not currently depend on any external frameworks or JavaScript libraries.

`index.html` contains the website's HTML and CSS. The `images` folder contains the photograph used in the introduction section. Keep the image in that folder so it continues to display correctly.

## How to view it on your computer

1. Download or clone the project.
2. Make sure `index.html` and the `images` folder are in the same main project folder.
3. Open `index.html` in a browser.

You do not need to install any additional packages to view the website locally.
